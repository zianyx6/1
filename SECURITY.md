# Security

QuotaCorner is an unofficial local desktop customization. Its CDP connection can access the client renderer. Only run a copy you trust; never bind the debugging endpoint to a network interface.

No API key is needed. QuotaCorner does not read authentication-file contents, send chat messages, perform automatic continuation, request community forecasts, or update itself. The official Codex CLI owns authentication and network requests for subscription data. Session metrics are derived locally from session logs.

The runtime package contains JavaScript and PowerShell/VBS source, not bundled executables. Node.js and the installed official client are required. User-specific executable paths and runtime files are excluded from Git and release archives.

For a suspected vulnerability, contact the repository owner privately through their GitHub profile if a private channel is available. Do not post tokens, account responses or private chat logs in issues.
